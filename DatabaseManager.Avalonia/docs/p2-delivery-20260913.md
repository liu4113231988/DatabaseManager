本轮以根目录 Roadmap.md 的九项 P2 为范围；结果网格布局记忆暂缓，ER 图与完整多数据库实例矩阵继续保持暂缓。主窗口图片工具菜单入口及其处理器已移除。

## 入口与使用方式

在「工具 → 数据工作台」选择查询构建、测试数据、质量剖析、数据字典、AI SQL、连接迁移、扩展导入或数据脱敏；仪表盘仍在「工具 → 仪表盘」。工作台顶部选择连接和数据库后加载对象。不同功能共用下方预览区，可切换到数据预览，表格最多显示 1000 行。

| 功能 | 完整流程 | 验证结果 |
| --- | --- | --- |
| 查询/视图构建 | 加入或拖入表 → 字段/关联/条件组/聚合/排序 → 预览 → 新查询标签；设计可保存/加载 | 核心 SQL/转义/非法关联测试、实际 UI 生成 SQL、PostgreSQL 关联聚合视图执行通过 |
| 测试数据 | 读元数据 → 列规则/种子 → 外键候选 → 预览 → 确认事务插入 | 固定种子、唯一空间不足、正则限制测试；UI 生成预览；PostgreSQL 30 行带外键批次实际写入通过 |
| 质量剖析 | 有限读取 → 汇总 → 按问题/列筛选 → 导出 JSON | NULL 与空字符串区分、重复余数、分布、数值极值/IQR、手机号优先识别；真实表及采样上限测试通过 |

## 边界与使用限制

- 数据库通用代码不等于全数据库实例验收。本轮真实数据库验证使用本地 PostgreSQL 随机测试 Schema、隔离 SQLite 文件；不改动已有业务表。其他数据库实例验收继续暂缓。
- 查询构建提供 INNER/LEFT JOIN、两层界面条件分组与基本聚合/排序；设计服务支持嵌套条件，未实现复杂子查询/窗口函数画布。生成 SQL 不自动执行，CREATE VIEW 也须在查询标签中执行。
- 数据生成每批最多 10000 行。正则支持字面量、字符范围、`\d`/`\w`/`\s` 与有限 `{n}`/`{min,max}`，不支持任意 .NET 正则；不支持语法会在写入前失败。唯一性先检查本批，与已有值冲突、列长度及其他数据库约束由事务提交验证，失败回滚；不是自动适配所有业务 CHECK 约束。外键每组最多 200 个候选，复合外键整组取值；父表先生成，不自动生成依赖图中的多表数据。
- 质量剖析最多 100000 行、200 万单元格和约 32 MiB 文本预算。超行数标记采样，超内存预算要求降低行数；分布显示前十值。IQR 是统计提示，重复值不等于违反唯一性，格式识别为样本推断。
- PDF 使用标准 CJK CID 字体，支持已复核的中文与拉丁文本；不嵌入用户字体，不保证 emoji/所有扩展字符显示。模板为纯文本占位符，不执行脚本。文档新建计划默认停用，用户在调度窗口核对路径、时间并启用；客户端需保持运行。
- AI 远程接口要求 HTTPS，本地回环允许 HTTP；禁用自动重定向，响应最多 2 MiB，120 秒超时。只发送用户明确选择的元数据、SQL 和请求，不发送行数据、连接密码。真实模型及回答质量未验收，不把模拟接口测试宣称为模型实测。
- 连接迁移最多 200 个连接，携带密码需至少 12 位保护口令，使用 PBKDF2-SHA256（210000 次）派生密钥及 AES-256-GCM。私钥文件内容不打包，导入后需检查本机路径。只新增/改名/跳过，不覆盖已有连接。
- Access/ODBC 依赖本机同位数驱动，取消连接和查询的及时性受驱动影响。DBF 直接读取支持 dBASE III 的 C/N/F/L/D 列并跳过已删除记录；Memo、FoxPro 和其他类型可尝试对应 ODBC 驱动，未宣称直接解析支持。单快照最多 100 万行；续导使用同一个快照，NULL/空值沿用原 CSV 导入语义。
- 仪表盘计算字段支持 decimal 四则运算、括号和 `[列名]` 引用，非数值/缺失列/除零明确报错。筛选作用于查询返回的有限结果，按同名列精确匹配；联动候选最多 200 个。卡片按页、顺序和尺寸布局，未引入自由拖拽面板。HTML 导出为当前页图表快照，不是实时连接页面。
- 脱敏只应用于工作台的副本及此处导出的 CSV，不全局修改其他导出流程。原查询快照/采样被截断时，脱敏导出也仅包含这一范围；NULL/空字符串仍按 CSV 语义输出。
- 现有工程仍有可空性、资源加载等历史警告。部分 SQLite 测试临时文件可能由底层对象持有到进程退出，沿用 P0 记录中的未解决限制。

## 验证命令与产物

```powershell
dotnet build DatabaseManager.Avalonia/DatabaseManager.Avalonia.sln -nologo
dotnet run --project DatabaseManager.Avalonia/DatabaseManager.AppCore.RegressionTests
dotnet run --project DatabaseManager.Avalonia/DatabaseManager.Avalonia -- --smoke --p2
```

可选环境变量：`DBSMOKE_CONNSTR` 为专用 PostgreSQL 测试连接；`DBM_TEST_ODBC=1` 开启本机指定 Access/dBASE 驱动测试，`DBM_ACCESS_FIXTURE` 指向专用空 Access 测试文件。测试不会在日志中输出连接密码。UI 测试使用独立连接服务，避免执行已保存连接或计划。

截图位于忽略提交的 `artifacts/p2-ui`，PDF/快照验收文件位于 `artifacts/p2-tests`。模拟模型测试不调用外部付费服务。界面测试失败会保留非零退出码，且只在全部通过时生成 passed.txt。

实现参考：[Microsoft ODBC 文档](https://learn.microsoft.com/en-us/dotnet/api/system.data.odbc.odbcconnection.getschema)、[Ollama 兼容接口文档](https://docs.ollama.com/api/openai-compatibility)。新增依赖为 System.Data.Odbc 8.0.1。
